# rasp-livive-net
Rust Audio Shift Processor - Rust→WASM audio pitch/formant shifter for the browser. Opus decode + formant-preserving phase-vocoder processing in an AudioWorklet, with parametric pitch/timbre controls. General-purpose and voice-agnostic knobs targeting age/gender variation, plus a Robotize stage for robot-avatar voices.
